--------------------------------------------------------------------------------
OVERVIEW
--------------------------------------------------------------------------------
We are thrilled to announce js_ydlp v2.0.0-rc-1, a next-generation media
extraction and downloading engine in pure Vanilla JavaScript (Node.js ESM, zero
external runtime dependencies).

Built upon the battle-tested architecture of yt-dlp, js_ydlp has been engineered
from the ground up to be ultra-fast, modular, and laser-focused on the modern
web's dominant platforms: YouTube, TikTok, and direct progressive media streams.
It introduces an intuitive, developer-friendly modern API, zero-RAM streaming
chunk downloads, automatic universal H.264 recoding, rich music metadata discovery,
and targeted modular bundles.


--------------------------------------------------------------------------------
EXHAUSTIVE CAPABILITIES & FEATURE BREAKDOWN
--------------------------------------------------------------------------------

1. ULTRA-INTUITIVE MODERN API & DUAL NAMING CONVENTION
   * Direct Top-Level One-Liners (No class instantiation needed):
     - download(url, options): Download videos or audio in a single line.
     - downloadMusic(url, options) [or extractAudio]: Download tagged MP3s with
       cover art, genre, release year, and synced lyrics.
     - extractInfo(url, options) [or getInfo]: Extract complete metadata and
       available formats without downloading media files.
     - listFormats(url, print): Inspect available formats, resolutions, FPS,
       bitrates, video codecs (vcodec), and audio codecs (acodec).
     - downloadSeparate(url, options): Download pristine video streams and
       audio tracks separately as independent files.
     - downloadImage(url, targetPath): Download video thumbnails or standalone
       images (.jpg, .png, .webp, .gif, .svg).
     - getLyrics(url, options): Fetch plain and synchronized (.lrc) lyrics.
     - getMetadata(url): Resolve rich music metadata (genre, album, year).
   * Unified Default Export `ydlp`:
     - Functions both as an object with static helpers (`ydlp.download(...)`)
       and as a configurable factory function (`const client = ydlp(options)`).
   * Complete Dual Naming Support (camelCase & snake_case):
     - Every option and method supports both conventions (e.g. `output` and
       `outtmpl`, `skipDownload` and `skip_download`, `continueDl` and `continuedl`,
       `onProgress` and `progress_hooks`, `recodeVideo` and `recode_video`, etc.).
   * Fluent Chainable Builder:
     - new YoutubeDL().output('...').format('best').recode('mp4').onProgress(cb)

2. TIKTOK DEDICATED ENGINE
   * 100% Unwatermarked Stream Extraction:
     - Automatically extracts direct playback streams (`playAddr`) and
       adaptive bitrates from `bitrateInfo` (1080p, 720p, 540p).
     - Deprioritizes watermarked fallback streams (`downloadAddr`).
   * Sub-Millisecond Proof-of-Work WAF Challenge Solver:
     - Bypasses TikTok's client-side anti-scraping JavaScript challenge
       (`SHA-256(seed + nonce) === target`) natively in `< 2 ms`.
     - Zero headless browser or Puppeteer overhead.
   * Automatic Universal H.264 (AVC) Recoding:
     - TikTok delivers high-resolution (1080p) vertical streams in HEVC / H.265
       (`bytevc1`), which causes black screens on Windows Media Player, older
       smart TVs, and older mobile devices.
     - js_ydlp detects HEVC streams and automatically recodes them using FFmpeg
       to H.264 (`libx264`) with `yuv420p` pixel format, `aac` audio, and
       `+faststart` atom for instant, universal playback on ANY device or player.
   * Comprehensive URL Support:
     - Standard URLs (`https://www.tiktok.com/@user/video/...`)
     - Shortened URLs (`vm.tiktok.com`, `vt.tiktok.com`, `tiktok.com/t/`)
     - Embed and share URLs.

3. YOUTUBE DEDICATED ENGINE
   * Multi-Client Innertube Cascade:
     - Native fallback cascade (`ANDROID` -> `IOS` -> `WEB`) that bypasses
       bot-detection walls and sign-in requirements without needing cookies.
   * Native V8 Signature Deciphering (`YoutubeSigSolver`):
     - Automatically extracts and evaluates bytecode scrambling operations
       directly from YouTube's player JavaScript.
   * Proof-of-Origin Token Integration (`PoTokenProvider`):
     - Built-in provider for minting PO-Tokens when required.
   * VisitorData & Innertube Session Synthesis:
     - Generates valid session contexts matching official mobile clients.
   * Advanced Format Selection:
     - Full format filtering (`best`, `worst`, `bestvideo`, `bestaudio`,
       itag IDs, and custom predicate selector functions).

4. RICH MUSIC METADATA, COVER ART & SYNCHRONIZED LYRICS
   * Automated Online Database Discovery:
     - Integrates with public music databases (iTunes Search API) to resolve:
       * Official Primary Music Genre (Dance, Pop, Rock, Electronic, etc.)
       * Official Album Name
       * Official Release Year
   * Full ID3v2 Metadata Tagging:
     - Writes `TCON` (Genre), `TDRC` (Year), `TALB` (Album), `TPE1` (Artist),
       and `TIT2` (Title) into output MP3 files.
   * High-Resolution Album Cover Art Embedding:
     - Downloads the highest-resolution thumbnail or cover image and embeds
       it as an `APIC` front-cover frame within the MP3 container.
   * Lyrics Discovery & Embedding:
     - Searches open lyrics providers (LRCLIB) with fallback to video closed
       captions, embedding lyrics into the `USLT` ID3 frame.
   * Synchronized `.lrc` File Export:
     - Optionally generates timestamped `.lrc` files (`writeLrc: true`) for
       karaoke-style players.

5. STREAM-FIRST ZERO-RAM CHUNKING PIPELINE
   * Zero-RAM Buffering:
     - Consumes responses via Web `ReadableStream` (`getReader()`) or Node.js
       `pipeline` chunk-by-chunk.
     - Writes chunks incrementally to a temporary `.part` file on disk.
     - Memory footprint remains flat and minimal (~KB) whether downloading
       a 3 MB song or a 50 GB 4K video.
   * HTTP 206 Partial Content & Range Resumption:
     - Automatically resumes interrupted downloads from the exact byte where
       the connection dropped using `Range: bytes=<length>-`.
   * Atomic File Renaming:
     - Files only receive their final extension once the entire byte stream
       has finished and verified.
   * Real-Time Progress Metrics:
     - Emits callbacks every 250 ms with accurate metrics: speed (bytes/sec),
       ETA (seconds), downloadedBytes, totalBytes, percentage, and elapsed time.

6. FORMAT & CODEC INSPECTION (-F / listFormats)
   * Equivalent to `yt-dlp -F`:
     - Displays formatted ASCII table showing Format ID, extension, resolution,
       FPS, estimated filesize, video codec (`vcodec`), audio codec (`acodec`),
       and format notes.
   * Separate Video & Audio Downloading:
     - Concurrently downloads the best adaptive video stream and audio stream
       without muxing them (`downloadSeparate`).

7. IMAGE & THUMBNAIL DOWNLOADER
   * Direct download of video thumbnails or standalone images (.jpg, .png,
     .webp, .gif, .svg) to disk (`downloadImage`).

8. NETWORKING & COOKIE MANAGEMENT
   * `CookieJar` with full Netscape format import/export.
   * `RequestDirector` supporting custom headers, redirects, and session state.

9. MODULAR NINJA BUILD PIPELINE (build.cmd / build.sh)
   * Advanced Terser Minification:
     - Full variable identifier mangling and obfuscation.
     - 100% comment and JSDoc stripping.
     - 2-pass dead code elimination.
   * Target-Specific Bundle Modularity:
     - ALL: Complete bundle (YouTube + TikTok + Direct Streams) ~66 KiB minified.
     - YOUTUBE: Lean bundle with 0 TikTok code ~60 KiB minified.
     - TIKTOK: Lean bundle with 0 YouTube code ~59 KiB minified.
   * Automated Pre-Flight & Post-Linking Integrity Tests:
     - Verifies exports, template expansion, comment stripping, and runs
       separate video/music download linking tests on every build.

10. QUALITY, TESTING & COMPLIANCE
   * 47/47 passing automated unit tests (`npm test`).
   * Apache License 2.0.
   * Open AI Statement headers present on 100% of codebase files.
